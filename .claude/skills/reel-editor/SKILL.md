# reel-editor — 릴스 전문 편집

센터장이 촬영만 하면 나머지 편집은 전부 Claude가 맡는다. 센터장에게 편집 프로그램 사용을 요구하지 않는다.

## 폴더 구조 (작업 폴더 `지구`)

```
지구/
├── CLAUDE.md                ← 기본 규칙
├── brand/                   ← 로고, 색, 말투(voice.md), 기록(log.md)
│   └── scripts/*.json       ← 편별 편집 계획 (자막·제목·훅)
├── 원본/                    ← 센터장이 찍은 영상을 넣는 곳
├── 완성본/                  ← 편집 결과가 나오는 곳
└── .claude/skills/          ← reel-editor, ig-* 스킬
```

`원본/`, `완성본/`이 없으면 만든다.

## 0. 준비 점검 (처음 한 번)

```bash
ffmpeg -version | head -1 && python3 --version
```

- ffmpeg가 없으면 설치한다. Mac: `brew install ffmpeg` (brew가 없으면 센터장에게 설치 안내). Windows: `winget install Gyan.FFmpeg`.
- 한글 폰트(나눔고딕, OFL)는 `fonts/`에 들어 있다. 따로 설치하지 않는다.

## 1. 원본 확인

1. `원본/` 안의 영상 목록, 길이, 해상도, 방향을 `ffprobe`로 확인한다.
2. 파일 이름이 `01_합동수업.mp4`, `02_빗소리수업.mp4`, `03_평범한하루.mp4`와 다르면 어떤 영상이 몇 편인지 센터장에게 한 번에 묻고, 이름을 맞춰 바꾼다.
3. 여러 클립을 찍었으면 `ffmpeg concat`으로 대본 순서대로 이어 붙여 `원본/{편}.mp4` 하나로 만든다.
4. 영상 중간 프레임 몇 장을 캡처해서 직접 보고, 얼굴이 정면으로 나온 아이가 있으면 센터장에게 알린다 (모자이크 여부 확인).

## 2. 자막 타이밍 맞추기

`brand/scripts/{편}.json`의 자막 시간은 대본 길이로 추정한 값이다. 실제 말과 맞춘다.

- **자동 (권장):** `pip install faster-whisper`가 되면 음성을 인식해서 각 자막의 start/end를 실제 발화 시간에 맞춘다. 대본 문장은 그대로 쓰고 시간만 가져온다 (인식된 글자로 자막을 바꾸지 않는다).
- **수동:** 자동이 안 되면 영상 전체 길이에 맞춰 비율대로 늘리거나 줄인다.
- 센터장이 대본과 다르게 말했으면, 실제로 한 말에 맞춰 자막 문장을 고친다. 존댓말 유지.
- 앞뒤 군더더기(카메라 켜고 끄는 부분)는 `"trim": [시작초, 끝초]`로 자른다.

## 3. 렌더

```bash
cd brand/scripts
python3 ../../.claude/skills/reel-editor/render.py 01_합동수업.json --preview   # 앞 8초 미리보기
python3 ../../.claude/skills/reel-editor/render.py 01_합동수업.json             # 완성본
```

plan.json 항목:

| 키 | 뜻 |
|---|---|
| `input` / `output` | 원본, 완성본 경로 (json 파일 기준 상대경로) |
| `trim` | `[시작, 끝]` 초. 생략하면 전체 |
| `title`, `title_highlight` | 상단 고정 제목, 금색으로 칠할 단어 |
| `hook.text`, `hook.highlight` | 첫 2초 중앙 팝업 텍스트 |
| `hook.zoom` | 첫 2초 급 줌인 (기본 true) |
| `subtitles[]` | `start`, `end`, `text`(줄바꿈 `\n`, 2줄 이하), `highlight` |
| `watermark` | 우상단 작은 글씨 |
| `end_card` | 로고 엔딩 길이(초). 0이면 없음 |

render.py가 자동으로 하는 것: 1080×1920 크롭, 0~0.3초 25% 급 줌인 후 복귀, 훅 텍스트 팝업, 제목·자막·워터마크(인스타 UI 가림 영역 밖), 로고가 왼쪽→오른쪽으로 드러나는 2초 엔딩, -14 LUFS 음량 정규화.

## 4. 검수 (센터장에게 보내기 전에 반드시)

1. 0.1초, 1초, 중간, 엔딩 프레임을 캡처해서 직접 본다: 자막이 얼굴을 가리지 않는지, 글자가 잘리지 않는지, 제목이 겹치지 않는지.
2. 자막이 가리면 해당 자막을 더 짧게 나누거나 줄 수를 줄인다. 그래도 가리면 render.py의 Sub 스타일 MarginV 값을 조정한다.
3. 첫 2초에 👁 줌인+텍스트 / 👂 질문형 첫마디 / 🏷 상단 제목이 모두 있는지 확인한다.
4. 진단명, 부모 탓, 아이 얼굴 노출이 없는지 확인한다.

## 5. 전달

- 완성본은 `완성본/{편}_완성.mp4`.
- 센터장에게 편별로: 길이, 첫 2초 구성, 확인할 점(얼굴·자막 오타)을 짧게 알린다.
- 캡션은 `/ig-caption`, 업로드 기록은 `brand/log.md`에 추가한다.

## 하지 않는 것

- 인스타그램에 직접 올리지 않는다. 업로드는 센터장이 한다.
- 저작권이 불분명한 음악을 깔지 않는다. 배경음이 필요하면 인스타 앱에서 고르도록 안내한다.
- 원본 파일을 덮어쓰지 않는다.
